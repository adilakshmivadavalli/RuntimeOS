# Regulatory source notes

The seed file intentionally contains short, illustrative summaries and links only to public official domains. It does **not** embed legal text.

Recommended sources for an actual evidence corpus:
- Reserve Bank of India — KYC Master Directions: https://www.rbi.org.in/
- Reserve Bank of India — Fraud Risk Management directions: https://www.rbi.org.in/
- India Code — Prevention of Money-laundering Act, 2002: https://www.indiacode.nic.in/

For production or legal use, ingest the current official document versions into Snowflake and store document/version metadata with each chunk.
